analytics Project Overview

Traditional volatility indicators like VIX treat each data point independently. But market stress rarely manifests in just one dimension—during COVID crash (March 2020), we saw simultaneous spikes in volatility, unusual volume, and correlation breakdowns.

psychology
Core Hypothesis: By modeling market behavior as a joint distribution across multiple features, we can detect statistically anomalous states that single-feature indicators miss.

compare_arrows This is probabilistic anomaly detection—we measure how "unlikely" each day's observation is under the learned distribution.

Multivariate Gaussian

info

Market state modeled as:

xt ~ N(μ̂t, Σ̂t)

Parameters estimated via Maximum Likelihood from trailing 60 trading days. Regularization (εI) ensures positive definiteness.

Mahalanobis Distance

info

Anomaly score via generalized distance:

D² = (x-μ)ᵀ Σ⁻¹ (x-μ)

Under H₀, D² ~ χ²(4). This provides a principled threshold framework.

Detection Criterion

info

Anomaly flagged when:

D²t > Q0.995(D²)

Percentile-based threshold is robust to fat tails in return distributions.
